# Online Store Sales Analysis

## Project Overview
This project analyzes simulated online store order data using Microsoft Excel. The goal is to organize sales data, summarize business performance, and present key metrics through PivotTables and charts.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts and Dashboard
- Data Cleaning

## Dataset
The dataset contains simulated online store order information, including order dates, products, quantities, prices, payment methods, order statuses, and total prices.

## Analysis
The project includes data cleaning, sales summaries, and visual analysis to explore sales performance and order-related patterns.

## Note
This project uses simulated data for learning and portfolio purposes. It does not contain real customer or business data.
